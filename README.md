# Business CRM Dashboard

Full-stack-style CRM portfolio application for managing customer records, sales opportunities and business workflows through a responsive dashboard.

## Features
- Create customer / lead records
- Read and search CRM records
- Update existing records
- Delete records with confirmation
- Sales-stage filtering
- Opportunity value tracking
- Dashboard KPIs
- Responsive admin interface
- Browser-local persistent data storage

## CRUD
The application demonstrates the complete Create, Read, Update and Delete workflow. Records include customer, company, email, opportunity value, sales stage and notes.

## Data Layer
This portfolio version uses `localStorage` as its persistent browser data layer, allowing the demo to run without external credentials or infrastructure. The UI and CRUD architecture are designed so the data layer can later be replaced with PostgreSQL/Supabase or a REST backend.

## Stack
HTML5, CSS3, JavaScript, Web Storage API, responsive dashboard UI.
